# Map label glyphs

Pre-built font glyphs (`.pbf`) that let the map draw text: place names, river and
street names along their lines, and Amharic (Ethiopic) script.

- Typeface: **Noto Sans** (Regular, Medium, Italic) — © The Noto Project Authors,
  licensed under the **SIL Open Font License 1.1** (https://openfontlicense.org).
- Glyph files: copied from the Protomaps `basemaps-assets` repository
  (https://github.com/protomaps/basemaps-assets), generated with MapLibre
  `font-maker`.
- Ranges included: Basic Latin and Latin extensions (0-1023, 7680-7935), general
  punctuation (8192-8447) and Ethiopic (4608-5119, U+1200–U+13FF).

Each font stack lists a single font because a static host cannot merge fonts.
